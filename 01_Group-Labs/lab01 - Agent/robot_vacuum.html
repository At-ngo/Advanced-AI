PEAS description of the cleaning phase¶

The PEAS description is used in the design phase for an intelligent agent. Make sure your implementations follow this description:

  • Performance Measure: Each action costs 1 energy unit. The performance is measured as the sum of the energy units used to clean the whole room.

  • Environment: A room with $n \times n$ squares where $n = 5$. Dirt is randomly placed on each square with probability $p = 0.2$. For simplicity, you can assume that the agent knows the size and the layout of the room (i.e., it knows $n$). To start, the agent is placed on a random square.

  • Actuators: The agent can clean the current square (action suck) or move to an adjacent square by going north, east, south, or west.

  • Sensors: Four bumper sensors, one for north, east, south, and west; a dirt sensor reporting dirt in the current square.

The agent program for a simple randomized agent¶

To show the structure of an agent program, I implement here a simple randomized agent that chooses its actions randomly.

The agent program is implemented as a function that gets sensor information (the current percepts) as the arguments. We will use the parameters:

  • bumpers: A dictionary with boolean entries for the for bumper sensors north, east, west, south. E.g., if the agent is on the north-west corner, bumpers will be {"north" : True, "east" : False, "south" : False, "west" : True}.
  • dirty: A boolean representing the dirt sensor.

The agent returns the chosen action as a string.

def simple_environment(agent_function, max_steps, verbose = True):
    num_cleaned = 0
    
    for i in range(max_steps):
        dirty = True
        bumpers = {"north" : False, "south" : False, "west" : False, "east" : False}

        action = agent_function(bumpers, dirty)
        if (verbose): print("step", i , "- action:", action) 
        
        if (action == "suck"): 
            num_cleaned = num_cleaned + 1
        
    return num_cleaned

import numpy as np

def create_room(n, p=0.2):
    return np.random.rand(n, n) < p


def environment(agent_function, n=5, p=0.2, max_steps=10000, verbose=False):

    room = create_room(n, p)                            # True = dirty
    pos = [np.random.randint(n), np.random.randint(n)]  # [row, col], agent starts on a random square

    for step in range(max_steps):
        # stop as soon as every square is clean -- this IS the performance measure
        if not room.any():
            return step

        r, c = pos
        bumpers = {
            "north": r == 0,
            "south": r == n - 1,
            "west":  c == 0,
            "east":  c == n - 1,
        }
        dirty = bool(room[r, c])

        action = agent_function(bumpers, dirty)

        if verbose:
            print(f"step {step:4d}: pos=({r},{c}) dirty={dirty} bumpers={bumpers} -> action=\'{action}\'")

        if action == "suck":
            room[r, c] = False
        elif action == "north" and not bumpers["north"]:
            pos[0] -= 1
        elif action == "south" and not bumpers["south"]:
            pos[0] += 1
        elif action == "west" and not bumpers["west"]:
            pos[1] -= 1
        elif action == "east" and not bumpers["east"]:
            pos[1] += 1
        # if the action would bump into a wall (or is invalid), the agent just stays put
        # -- this still costs one energy unit, exactly as a real bump would.

    # ran out of energy before the room was fully clean
    return max_steps

def simple_reflex_agent(bumpers, dirty):

    if dirty:
        return "suck"

    free_directions = [d for d in ("north", "east", "west", "south") if not bumpers[d]]
    return np.random.choice(free_directions)

Agent state design¶

The model-based agent needs to guarantee that it visits every square in the room, not just wander randomly, otherwise it could miss dirty squares forever. To do this it keeps three pieces of state:

  • located (bool): whether the agent has already found the north-west corner (0, 0). Bumpers are 100% reliable, so the agent first walks north until the north bumper fires, then west until the west bumper fires. Once both have fired, the agent knows its exact position - this is the only way a memory-less percept stream (bumpers + dirt) can be turned into a coordinate.
  • path (list[str]): a boustrophedon ("ox-plough", zig-zag) sequence of moves computed once from the known room size n (allowed by the PEAS description: "the agent knows the size ... of the room"). Going east across row 0, south once, west across row 1, south once, east across row 2, etc. visits every one of the n x n squares exactly once using only n^2 - 1 moves.
  • path_index / sucked_current_cell: which move comes next, and whether the agent has already decided whether to suck the square it is currently standing on.

Because the traversal order does not depend on where the dirt actually is, the agent is guaranteed to eventually visit every square - and it stops early (the environment loop exits) as soon as all discovered dirt has been sucked up, so on average it usually finishes well before visiting all n^2 squares.

def boustrophedon_path(n):
    path = []
    for row in range(n):
        direction = "east" if row % 2 == 0 else "west"
        path += [direction] * (n - 1)
        if row < n - 1:
            path.append("south")
    return path


class ModelBasedVacuumAgent:

    def __init__(self, n):
        self.n = n
        self.located = False
        self.path = boustrophedon_path(n)
        self.path_index = 0
        self.sucked_current_cell = False

    def _should_suck(self, dirty):
        # its own method so the noisy-sensor version (Advanced task) can override it
        return dirty

    def act(self, bumpers, dirty):
        # Phase 1: find the NW corner using the (reliable) bumper sensors
        if not self.located:
            if not bumpers["north"]:
                return "north"
            if not bumpers["west"]:
                return "west"
            self.located = True

        # Phase 2: sweep the room in a fixed zig-zag order
        if not self.sucked_current_cell:
            self.sucked_current_cell = True
            if self._should_suck(dirty):
                return "suck"

        if self.path_index < len(self.path):
            move = self.path[self.path_index]
            self.path_index += 1
            self.sucked_current_cell = False
            return move

        return "suck"  # sweep finished; nothing meaningful left to do

# Answers goes here

Rectangular room of unknown size. The locate phase (walking to the NW corner) still works, since it only relies on the two reliable bumpers. But the pre-computed zig-zag path needs to know n in advance - for an unknown/rectangular size, the agent would instead need to discover the far bumpers while sweeping (e.g., walk east until the east bumper fires to learn the row length, then go south one row at a time until the south bumper fires to learn the number of rows), building the path incrementally instead of computing it upfront.

Irregular shape (e.g. a hallway connecting two rooms). The fixed zig-zag path assumes a solid rectangle; it would walk straight through squares that don't exist and never notice a hallway branching off to a second room, so parts of the space would simply never be visited. A depth-first / wall-following ("always keep a hand on the left wall") strategy that reacts to bumpers as they occur, rather than following a precomputed plan, generalizes much better to irregular layouts.

Obstacles the agent doesn't know about. An obstacle triggers a bumper exactly like an outer wall does, so the agent's locate phase would stop early (thinking it has reached a corner when it has really just bumped into furniture), corrupting its internal coordinate system - the rest of the precomputed sweep would then be based on a wrong map and likely skip real squares or revisit others. The agent would need to treat "bumper fired but I'm not yet where the plan expected" as a sign to replan locally rather than trusting the fixed path blindly.

Dirt sensor wrong 10% of the time. Since our model-based agent's movement never depends on the dirty percept (only the "should I suck here?" decision does), the zig-zag sweep still visits every square in the same fixed number of moves - but around 10% of truly dirty squares would be perceived as clean and skipped (never sucked), and around 10% of clean squares would trigger a harmless, wasted suck. So the n^2-ish energy cost stays about the same, but the room ends up not fully clean. See the Advanced task below for a fix.

Bumper sensor wrong 10% of the time (occasionally fails to report a wall). This is more damaging, because the locate phase and the whole zig-zag path depend on bumpers being ground truth. A missed wall reading during locating could make the agent think it reached the corner one square too early or too late, silently shifting its whole internal coordinate frame - every subsequent move in the sweep would then be based on a wrong position, and the agent could "walk off" its internal map or bump into a real wall it wasn't expecting, with no way to detect that its coordinates have drifted. Making the agent robust to this would need redundancy - e.g., confirming a wall with more than one reading before trusting it - rather than the current single-reading design.

def noisy_environment(agent_function, n=5, p=0.2, sensor_noise=0.1, max_steps=2000, verbose=False):
    room = create_room(n, p)
    pos = [np.random.randint(n), np.random.randint(n)]

    for step in range(max_steps):
        r, c = pos
        bumpers = {
            "north": r == 0, "south": r == n - 1,
            "west":  c == 0, "east":  c == n - 1,
        }
        true_dirty = bool(room[r, c])
        dirty = (not true_dirty) if (np.random.rand() < sensor_noise) else true_dirty

        action = agent_function(bumpers, dirty)

        if verbose:
            print(f"step {step:4d}: pos=({r},{c}) true_dirty={true_dirty} sensed={dirty} -> action=\'{action}\'")

        if action == "suck":
            room[r, c] = False  # the actuator itself is perfectly reliable
        elif action == "north" and not bumpers["north"]:
            pos[0] -= 1
        elif action == "south" and not bumpers["south"]:
            pos[0] += 1
        elif action == "west" and not bumpers["west"]:
            pos[1] -= 1
        elif action == "east" and not bumpers["east"]:
            pos[1] += 1

    return max_steps, int(room.sum())
